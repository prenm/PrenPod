# PrenPod

An iPod-style music player for Android, made by Pren.

**Latest (r6):** https://github.com/prenm/PrenPod/raw/main/PrenPod.apk

When the file finishes downloading, open it. If Android asks, allow installs from your browser, then tap Install.

## Revisions

| Revision | Download | What changed |
|---|---|---|
| r7 (latest) | [PrenPod-r7.apk](https://github.com/prenm/PrenPod/raw/main/PrenPod-r7.apk) | The loading progress is now one small line at the bottom, so the splash screen stays fully visible. Intro text moved up slightly. |
| r6 | [PrenPod-r6.apk](https://github.com/prenm/PrenPod/raw/main/PrenPod-r6.apk) | Signed release build (31 MB). Animated splash. Fits any phone or tablet without stretching. Phones stay upright, tablets rotate. Updates install over each other from here on. |

Earlier test builds (r1 to r5) were debug builds. Uninstall them before installing r6.
