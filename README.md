# PrenPod

An iPod-style music player for Android, made by Pren.

**Latest (r6):** https://github.com/prenm/PrenPod/raw/main/PrenPod.apk

When the file finishes downloading, open it. If Android asks, allow installs from your browser, then tap Install.

## Revisions

| Revision | Download | What changed |
|---|---|---|
| r9 (latest) | [PrenPod-r9.apk](https://github.com/prenm/PrenPod/raw/main/PrenPod-r9.apk) | Fix Album Art is now fast: it checks several songs at once with Deezer (about 8 a second), so a whole library takes a few minutes. MusicBrainz is only used for the few songs Deezer cannot place. |
| r8 | [PrenPod-r8.apk](https://github.com/prenm/PrenPod/raw/main/PrenPod-r8.apk) | Fix Album Art: identifies each song on MusicBrainz, finds the right cover (Cover Art Archive, then iTunes, then Deezer), shows a review list, then fixes tags and renames files to "Artist - Title". |
| r7 | [PrenPod-r7.apk](https://github.com/prenm/PrenPod/raw/main/PrenPod-r7.apk) | The loading progress is now one small line at the bottom, so the splash screen stays fully visible. Intro text moved up slightly. |
| r6 | [PrenPod-r6.apk](https://github.com/prenm/PrenPod/raw/main/PrenPod-r6.apk) | Signed release build (31 MB). Animated splash. Fits any phone or tablet without stretching. Phones stay upright, tablets rotate. Updates install over each other from here on. |

Earlier test builds (r1 to r5) were debug builds. Uninstall them before installing r6.
